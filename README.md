# Site EFRAYIM

Site vitrine statique en français, réalisé en HTML, CSS et JavaScript sans compilation.

## Prévisualiser
Ouvrir index.html dans un navigateur, ou publier le contenu de ce dossier sur un hébergement web statique.

## Fichiers
- index.html : contenu et sections de la page
- styles.css : identité visuelle et mise en page responsive
- script.js : navigation mobile et année du pied de page
- assets/logo.png : logo EFRAYIM fourni

Les images d’illustration et les polices sont chargées depuis Unsplash et Google Fonts. Les liens téléphone et WhatsApp utilisent l’indicatif +228. Aucun domaine n’est présumé enregistré.

## Publier avec GitHub Pages

Le dépôt inclut un workflow GitHub Actions dans .github/workflows/deploy.yml. Après avoir créé un dépôt GitHub et poussé ces fichiers sur la branche main, active GitHub Pages dans Settings > Pages avec Source = GitHub Actions. Le workflow publiera le site automatiquement et générera sitemap.xml avec son URL publique. Pour un compte GitHub Free, le dépôt doit être public.
